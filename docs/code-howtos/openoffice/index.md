# The LibreOffice Panel

Start with the current [architecture overview](overview.md) and [citation ordering guide](order-of-appearance.md).
The [compatibility requirements](../../requirements/openoffice.md) and [ADR-0080](../../decisions/0080-canonical-writer-citations.md) describe canonical marks, next-CSL-insertion conversion of citation marks only, and the legacy-format boundary.
Bibliography synchronization remains separate: disabled synchronization leaves all bibliography sections unchanged, while enabled synchronization updates only the target mode's managed bibliography.
The code-reorganization and problems pages record historical behavior rather than the current storage contract.
