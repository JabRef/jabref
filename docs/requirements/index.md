# Requirements

Requirements capture what JabRef should do.
Think of them as a structured representation of implemented issues.

For more information on how to write requirements and use OpenFastTrace, see the [Requirements code-howto](../code-howtos/requirements.md).

The [OpenOffice/LibreOffice requirements](openoffice.md) cover citation compatibility across Writer style families, next-CSL-insertion conversion of citation marks only, unchanged bibliography synchronization, the legacy-format boundary, and single-step undo for group edits.
